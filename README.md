# 🔥 DapurMembara - Flame Recipe Finder & Culinary Sizzle

Aplikasi pencari resep makanan interaktif dengan tema **masakan berapi** (*Wok-Hei, Flambé, Grill Arang, Sizzling Hotplate, & Torched Aburi*) dengan visual hidangan menggugah selera, efek suara wajan mendesis nyata, partikel bara api, timer memasak, pembaca suara (voice reader), dan generator resep berbasis AI.

---

## ✨ Fitur Utama

1. **🔥 Visual & Sensasi Api Nyata**:
   - **Efek Partikel Bara Api (Flame Embers)**: Partikel bara api yang melayang di latar belakang aplikasi dengan kontrol on/off.
   - **Suara Sizzle Wajan (Web Audio API Synthesizer)**: Efek audio desisan wajan panas saat memasak yang disintesis secara langsung tanpa perlu koneksi audio eksternal.
   - **Tingkat Api & Kepedasan (Flame Heat Level 🔥 1-5)**: Indikator visual tingkat kobaran api dan panas masakan.

2. **📸 Koleksi Resep Masakan Menggugah Selera**:
   - *Wagyu Ribeye Flambé with Herb Garlic Butter*
   - *Ayam Bakar Taliwang Membara Khas Lombok*
   - *Nasi Goreng Naga Wok-Hei Spesial*
   - *Torched Aburi Salmon Volcano Roll*
   - *Korean Buldak Cheesy Fire Chicken*
   - *Sate Maranggi Sapi Arang Menyala*
   - *Sizzling Pepper Beef Rice Hotplate*
   - *Tom Yum Kung Seafood Hot Firepot*
   - *Classic Vanilla Crème Brûlée Torched*
   - *New Orleans Bananas Foster Flambé*
   - *Ikan Gurame Bakar Bumbu Jimbaran Membara*
   - *Cumi Bakar Kerat Saus Padang Berasap*

3. **🧊 Kulkas Ajaib (Pantry Search)**:
   - Pilih bahan-bahan yang Anda miliki di kulkas / dapur (Ayam, Daging, Telur, Cabai, Bawang, Salmon, Keju, dll.).
   - Aplikasi otomatis mencocokkan resep dengan persentase kecocokan bahan tertinggi!

4. **🧑‍🍳 Mode Masak Step-by-Step Interaktif**:
   - **Interactive Checklist Bahan**: Centang bahan yang sudah disiapkan.
   - **Pengatur Porsi Otomatis**: Ubah porsi (1, 2, 4, 8 porsi) dan takaran bahan akan dihitung otomatis.
   - **Kitchen Cooking Timer**: Timer hitung mundur terintegrasi dengan suara bel saat waktu memasak habis.
   - **Suara Chef (Voice Reader)**: Pembacaan instruksi langkah memasak secara hands-free menggunakan Web Speech API bahasa Indonesia.
   - **Peringatan Keamanan Api**: Tanda pengingat saat langkah melibatkan kobaran api atau wajan panas ekstrem.

5. **✨ AI Fire Recipe Generator**:
   - Masukkan bahan apa saja yang Anda miliki di dapur.
   - Pilih gaya api (Wok-Hei, Flambé, Torched, atau Arang).
   - Dapatkan resep berapi gourmet instan lengkap dengan panduan langkah.

6. **📖 Panduan Seni Api & Keamanan Dapur**:
   - Penjelasan teknik *Wok Hei*, *Flambé*, *Bara Arang*, dan *Aburi Torch*.
   - 5 Prinsip Keselamatan Api Dapur (penanganan minyak terbakar, ventilasi, dll.).

## 🚀 Cara Menjalankan

Aplikasi saat ini telah aktif di:
```
http://localhost:3000/
```

Jika ingin menjalankan ulang di kemudian hari:
```bash
cd d:\testProject\recipeFinderApp
npm install
npm run dev
```

Untuk build produksi:
```bash
npm run build
```
